# 🛒 CartShare – A Collaborative Shopping Cart Web Application

CartShare is a collaborative shopping cart web application developed using **HTML**, **CSS**, and **JavaScript**. It allows multiple users to create or join a shared shopping cart using a unique room code. The application helps users manage shopping lists, track shopping expenses, synchronize updates in real time, and generate a printable receipt.

---

## 📌 Project Overview

Managing shopping lists for families, friends, or roommates can be challenging. CartShare simplifies group shopping by providing a shared shopping cart where multiple users can collaborate efficiently.

---

## ✨ Features

- 🔹 Create a new shopping cart
- 🔹 Join an existing cart using a room code
- 🔹 Add shopping items
- 🔹 Edit shopping items
- 🔹 Delete shopping items
- 🔹 Live Summary
- 🔹 Live Activity Log
- 🔹 Automatic total calculation
- 🔹 Printable receipt
- 🔹 Real-Time Synchronization between browser windows

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open **index.html** in your web browser.
4. Create or join a shopping cart.
5. Add, edit, or delete shopping items.
6. Generate a printable receipt.
